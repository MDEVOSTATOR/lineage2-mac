# Lineage II on Apple Silicon — NNG Mac Community

Нативный macOS-лаунчер и управление тачпадом для совместимого 32-битного клиента
Lineage II High Five. Metal-рендер, ускорение x87, защита системной гаммы и
исправление двух воспроизведённых сбоев ресайза.

**Community preview.** Исходная связка проверена на MacBook Pro M5 Max с macOS
26.3.1 и конкретным клиентом NNG. Совместимость со всеми серверами, античитами,
Mac и версиями macOS не заявляется. Публичная упаковка использует отдельные
данные и требует готовую совместимую папку клиента.

[Скачать приложение](https://github.com/MDEVOSTATOR/lineage2-mac/releases)
· [Как устроено](docs/ENGINEERING.md) · [Проверки и ограничения](docs/VALIDATION.md)

## Что умеет

- Нативное приложение Swift/AppKit, запуск без платной оболочки CrossOver.
- Wine CX26 / Wine11, mtld3d 0.15.1 и x87sidecar с закреплёнными версиями и SHA-256.
- Два пальца **без клика** — поворот камеры; **⌘ Command + два пальца** — зум.
- Настройки чувствительности и скорости зума в окне настроек.
- Хелпер работает только с игровой сессией, перехватывает события только её PID
  и завершается при выходе игры. Отдельного значка в строке меню нет.
- Запрет изменения системной гаммы игрой и SDR-настройки рендера.
- Исправление известных сбоев перетягивания рамки; восстановление свёрнутого окна.

Рост примерно с 10 до 100+ FPS наблюдался владельцем в исходной тестовой связке.
Это результат конкретной сцены и оборудования, а не обещание одинакового FPS.
Сам ускоритель x87 и Metal-рендер разработаны upstream-проектами, указанными ниже.

## Требования

- Mac с Apple Silicon и установленной Rosetta 2.
- Wine upstream требует macOS 15+. Подтверждённая система проекта — **26.3.1**;
  более ранние версии для полной связки пока не проверены.
- Готовая **совместимая** папка клиента с `system/l2.exe` и `system/Engine.dll`.
  Если серверу нужны специальные Mac-совместимые модули, получите их у его
  разработчика. Проект их не поставляет и не обходит античит.
- Несколько ГБ свободного места для Wine, отдельного prefix и копии `system/`.

## Установка и запуск

1. Скачайте ZIP из Releases, распакуйте и перенесите **NNG Mac Community.app**
   в «Программы». Это отдельное приложение; существующая NNG Mac не заменяется.
2. Сборка подписана ad hoc и **не нотарифицирована Apple**. Если macOS её
   блокирует, используйте штатное «Конфиденциальность и безопасность → Всё равно
   открыть», только если доверяете источнику. Проверяемые хеши — в `SHA256SUMS`.
3. Нажмите **«Выбрать клиент…»** и укажите папку совместимого клиента.
   Программа создаёт отдельную копию `system/`, а игровые ресурсы использует
   через ссылки. **Не удаляйте и не перемещайте исходную папку.**
4. Нажмите **«Играть»**. Wine (~235 MB) загружается непосредственно из
   [upstream-релиза](https://github.com/athei/mach9/releases/tag/cx-26.3.0-9)
   и проверяется по размеру и SHA-256. Игра и серверные модули не скачиваются.
5. Для тачпада разрешите **NNG Mac Community** в «Системные настройки →
   Конфиденциальность и безопасность → Универсальный доступ».
   Окно настроек открывается через меню приложения → «Управление тачпадом…».

Клиент обновляйте средствами своего сервера. После обновления закройте игру и
выберите обновлённую папку повторно. Программа не запрашивает игровой пароль,
не хранит его в конфигурации лаунчера и не меняет сетевые маршруты/VPN.

Существующие пользователи локальной NNG Mac могут выбрать свою совместимую
папку `~/Library/Application Support/NNG Mac/compat/mac-client`. Это не переносит
Wine prefix или настройки сети из старой установки.

## Данные и удаление

Данные community-версии: `~/Library/Application Support/NNG Mac Community`.
Там находятся Wine, prefix, импортированная копия `system/`, настройки и логи.
Прежние импорты сохраняются в `compat/import-backups/` для ручного отката.
Исходная папка клиента остаётся на месте.

Для удаления закройте игру, удалите приложение и его отдельную папку данных.
Сохраните нужные игровые настройки перед удалением данных. Автозапуска, launchd,
сетевого сервиса или установки в системные каталоги нет.

## Сборка из исходников

Нужны Apple Silicon Mac, Xcode Command Line Tools, Python 3 и Go.

```sh
python3 scripts/build.py
```

Скрипт проверяет хеши upstream-архивов, собирает x87sidecar из закреплённого
исходного commit, кросс-компилирует mouse-only Windows bridge и собирает Swift
приложения. Готовый ZIP и `SHA256SUMS` появляются в `dist/`.
Wine и игровые файлы в ZIP не включаются. Зависимости/кеш — в `local/cache/`.
При отсутствии локального Go допустим `--bridge-exe /path/to/nng-input.exe`,
если он заранее собран из **этого** `Sources/WineInputBridge.go` для windows/386.

Проверка содержимого перед публикацией:

```sh
python3 scripts/check_publication.py
```

## Ограничения

- Публичная упаковка — preview; отделяйте проверенную исходную игровую связку
  от новых тестов на чистом prefix и других компьютерах.
- Известное падение клиента при выходе (`XMLDocument::Load` /
  `SceneEditorDrawerWnd`) остаётся нерешённым.
- Исправление ресайза адресует два конкретных пути mtld3d/старого UE2, а не
  доказывает отсутствие всех возможных ошибок рендера.
- Диагностический capture hotkey mtld3d отключён нашим совместимостным патчем.
- Переподписание ad hoc обновления иногда требует заново добавить приложение
  в тот же список «Универсальный доступ».
- Intel Mac в этом релизе не поддерживается. Проверки на M1/M2/M3/M4 пока нет.
