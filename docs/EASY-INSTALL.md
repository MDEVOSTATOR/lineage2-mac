# NNG Mac: установка одной кнопкой

Этот вариант устанавливает тот же клиент NNG через тот же NNG Updater v1.2.
Полный клиент (~11 ГБ) не входит в GitHub-релиз. Это отдельная установка:
существующая локальная NNG Mac не заменяется.

1. Скачайте **NNG-Mac-Easy-v1.4.0-preview.1-arm64.zip** из Releases.
2. Распакуйте и перенесите **NNG Mac Easy.app** в «Программы».
3. Откройте приложение и нажмите **«Установить и играть»**.
4. Если Rosetta отсутствует, приложение предложит принять условия Apple и
   установить её штатной программой macOS.
5. Для жестов разрешите **NNG Mac Easy** в «Системные настройки →
   Конфиденциальность и безопасность → Универсальный доступ».

При блокировке неподписанного доверенным сертификатом приложения используйте
штатную кнопку **«Всё равно открыть»** в настройках безопасности macOS.
Подпись сейчас ad hoc; нотарификации Apple нет. Отключать Gatekeeper не нужно.
Системные разрешения нельзя выдать за пользователя одной кнопкой лаунчера.

Требуются Apple Silicon, macOS 15+ по требованиям Wine, интернет и не менее
20 ГБ свободного места на обычном томе macOS без различия регистра имён.
Полная игровая связка проверялась на M5 Max / macOS 26.3.1; другие Mac и версии
системы ещё требуют реальной проверки. Intel Mac этим ZIP не поддерживается.

## Что устанавливается

- Rosetta — от Apple, только если её нет и пользователь принял условия.
- Тот же оригинальный NNG Updater — из закреплённого архива исходного сервера.
- Клиент NNG — апдейтером с исходного сервера, без игрового пароля в лаунчере.
- Совместимые Mac-модули — из исходного публичного архива L2Craft; весь архив
  и каждый используемый модуль сверяются с закреплёнными SHA-256.
- Wine CX26 — из закреплённого upstream-релиза GitHub с проверкой SHA-256.
- mtld3d / Metal, x87sidecar, исправления гаммы и ресайза — из нашего приложения.
- Шрифты — копируются из установленной macOS, не распространяются в релизе.
- Исправленные настройки — применяются как дельты только к известной исходной
  версии; пользовательские назначения клавиш сохраняются.

**Metal уже входит в macOS.** Устанавливается переводчик Direct3D 9 → Metal,
а не отдельная копия Metal.

Лаунчер показывает этапы, сохраняет журнал и уже скачанные файлы. При ошибке
нажмите «Повторить» или «Проверить обновления»; апдейтер докачает недостающее.
После установки основная кнопка называется «Играть» и работает с локальным
проверенным клиентом. Обновление доступно отдельной кнопкой, когда игра закрыта.
Закрытие окна лаунчера не прерывает работающую игру или её подготовку.

Два пальца без клика — камера. **⌘ Command + два пальца — зум.**
Настройки — меню приложения → «Управление тачпадом…» при запущенной игре.
Хелпер завершается вместе с игровой сессией, значка в строке меню нет.

## Данные, источники и ограничения

Все данные: `~/Library/Application Support/NNG Mac Easy`.
Приложение не переносит аккаунты, Wine prefix, VPN или маршруты автора сборки.
Сохраняются локальные журналы и предыдущая копия `system/` для отката.

Адреса исходных загрузок и хеши — `resources/easy-install.json`.
Оригинальный сервер NNG использует HTTP: закреплённый архив апдейтера
проверяется по хешу из приложения, но обновляемый игровой manifest сохраняет
исходную модель доверия серверу NNG. Лаунчер не выдаёт её за проверенную HTTPS-
доставку или за цифровую подпись разработчика игры.

Уже известное падение клиента при выходе (`XMLDocument::Load` /
`SceneEditorDrawerWnd`) не исправлено. Заявленный владельцем рост FPS относится
к исходной рабочей связке; одинаковый FPS на всех Mac не обещается.

## Сборка и проверка разработчиком

```sh
python3 scripts/build.py --easy
python3 scripts/check_publication.py
```

Для изолированной установки без запуска игры задайте новую отдельную папку:

```sh
NNG_STATE_ROOT="$PWD/local/my-clean-test" \
  "build/NNG Mac Easy.app/Contents/MacOS/nng" --setup-only
```

Rosetta должна быть установлена; CLI без явного флага согласия не принимает
лицензию за пользователя. Не задавайте для испытаний папку рабочей игры.
