# Инженерные решения

## FPS: Rosetta, x87 и реальный backend

В исходной связке активное окно давало около10–12FPS при небольшой загрузке GPU.
CPU samples показали существенную работу в x87/softfloat-пути Rosetta старого
32-битного клиента. Изменение одного лимита кадров/MSync проблему не решило.
Переход на совместимую Wine11/CX26-сборку с x87sidecar и реально загруженным
mtld3d дал владельцу100+FPS в проверенной игровой сцене.

x87sidecar — upstream JIT Lifeisawful/athei, mtld3d — upstream D3D9→Metal
Alexander Theissen. Наш вклад: рабочая интеграция, закреплённая сборка,
проверки настоящих загруженных библиотек и исправления конкретных несовместимостей.
Надпись «Metal» в настройках сама по себе не считается доказательством backend.
Игра конкурирует за GPU с фоновыми задачами; контрольного A/B для каждого
наблюдавшегося падения FPS не проводилось.

## Гамма и HDR

У исходной игры была измерена изменённая системная gamma transfer table:
поднятый чёрный и обрезанные светлые тона. `color.hdr.enable=false` в рендере
сам по себе не блокирует вызов игрового `SetDeviceGammaRamp`.

Используются две меры:

- `AllowSetGamma=N` в Wine `AppDefaults\l2.exe\Mac Driver`.
- `color.hdr.enable=false` и `color.space=accurate` в локальном `mtld3d.conf`.

В исходной установке системные таблицы RGB совпали с baseline без игры
(max delta0). Community-версия применяет политику только в своём prefix;
системный HDR и настройки остальных приложений не меняются.

## Два сбоя ресайза

В mtld3d0.15.1 воспроизведены два механизма:

1. Обработчик `WM_SIZE` меняет backbuffer до того, как игра обработала resize.
   Старый прямоугольник рисования больше нового target → `D3DERR_INVALIDCALL`.
2. Опрос диагностического capture hotkey через `GetAsyncKeyState` внутри
   `Present` позволяет Wine обработать оконные события повторно. Игра удаляет
   старое устройство и создаёт новое, а незавершённый `Present` продолжает
   пользоваться освобождённым `DeviceInner`. Старый указатель был пойман
   отладчиком уже после создания нового устройства.

NNG-specific patch пропускает renderer autoresize-ветку и capture hotkey poll.
Всего9изменённых байт, только в **открытом рендере**, без патчей клиента игры.
Исходный SHA-256, байты, цели переходов и отсутствие пересечения с PE HIGHLOW
relocations проверяются скриптом. Диагностический capture hotkey отключается.
Это адресное исправление двух путей, а не общая гарантия reentrant-безопасности.

В исходной установке пройдены20настоящих native edge drags в изолированном
тесте, в том числе после minimize/restore, и ещё2в установленном приложении.
Эти тесты проводились на экране входа. Все игровые сцены не перебирались.

## Тачпад и освобождение кнопки

Native helper перехватывает `scrollWheel` и `flagsChanged` только для PID игры.
Два пальца без клика преобразуются в относительное движение с удержанием RMB;
⌘+два пальца — в Windows wheel. Mouse-only bridge общается через приватные
stdin/stdout pipes внутри того же Wine prefix. Серверов и keyboard hooks нет.

Учитываются generic и left/right bits Command. Они удаляются из scroll/modifier
копии, передаваемой Wine, чтобы не включать внутриигровой Alt-camera binding.
`keyDown`/`keyUp` не входят в mask перехвата. Подписка на выход PID и смену
активного приложения заменяет постоянный опрос. RMB освобождается по окончании
жеста, потере фокуса, разрыву pipe и завершению helper.

Отдельный разбор «камера работает, зум нет» показал540событий с Command и ни
одного с Option: прежняя версия ожидала Option. Владелец подтвердил, что
Option работал, и выбрал Command. После1.3.4 им подтверждены оба режима.
Гипотеза потери Option в системных событиях для этого случая не подтвердилась.

## Почему отдельная community-упаковка

Исходные диагностические сборки опирались на локальные prefix, сторонние
серверные модули и историю миграций. Community preview импортирует совместимую
папку пользователя и создаёт отдельный prefix. В релиз не входят game binaries,
серверный updater, Wine prefix, логи владельца или его сеть. Wine загружается
с upstream с SHA-256; повторная локальная игра не требует сервера загрузки.
