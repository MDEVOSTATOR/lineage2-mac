# Проверки и границы результата

## Исходная установленная1.3.4

Проверено на MacBook Pro M5 Max, macOS26.3.1, совместимом32-битном High Five
клиенте NNG:

- Запуск, вход на сервер и100+FPS в одной из сцен подтверждены владельцем.
- Два пальца без клика — камера; Command+два пальца — зум: подтверждены владельцем.
- Хелпер завершается вместе с игровым PID; наблюдалось0.0%CPU в idle.
- Запрет системной гаммы: RGB transfer tables совпали с baseline, max delta0.
- Ресайз:20native drags в isolated trial плюс2в установленной app, экран входа.
- Minimize/restore и восстановление через лаунчер проверялись в этой связке.

Это результаты исходной установки. Они не доказывают совместимость нового
импорта с любым Windows-клиентом или сервером.

## Community preview

- Окно новой community-сборки открыто и проверено; видны импорт клиента и
  отдельное имя приложения. Проверочное приложение завершено.
- Swift launcher и helper собраны под arm64, ad hoc подпись deep/strict проверена.
- Windows mouse bridge заново собран для windows/386 из опубликованного исходника;
  `go vet` прошёл. Go build использует `-trimpath`.
- x87sidecar собран из закреплённого upstream commit; `--probe` supported на
  тестовом M5 Max. C/C++ file/debug paths нормализованы.
- Патч mtld3d совпал с принятым SHA-256,9байт; PE relocations проверены.
- Helper self-test: Command left/right/generic, записанный реальный флаг,
  режимы камеры/зума, сохранение Shift/Option и keyDown/up, fail-open при
  недоступном/устаревшем bridge, фрагментированный JSONL и EOF.
- Тесты настоящего CLI импорта на временных fixtures: исходник не меняется,
  assets доступны, изменяемый User.ini не считается повреждением, изменённый
  Engine.dll отвергается, lock активной игры соблюдается, предыдущий импорт
  сохраняется, symlink внутри system/ и рекурсивный импорт state отвергаются.
- Исправлена нормализация macOS `/var`/`/private/var` при формировании относительных
  путей импортированных файлов; тесты прогоняются и через временный каталог.
- Импорт настоящей совместимой папки клиента и повторная проверка её файлов прошли;
  исходная установка не изменялась.
- Новый отдельный Wine prefix инициализирован без копирования prefix владельца.
- В нём hidden-window D3D9 probe создал устройство (HRESULT0) и успешно выполнил
  Clear/Present12раз. Это проверка backend, не замер игрового FPS.
- Публичные исходники и app проверяются на credentials, личные абсолютные пути,
  частные IPv4, игровые бинарники и файлы prefix/account.

## Что ещё не принято

Полный вход в игровой мир через новую community-упаковку и все её жесты на
чистом пользовательском аккаунте; другие Mac/версии macOS/серверы; Windows-клиенты
с иными античитами; долгие игровые сессии; все варианты выхода и смены разрешения.
Preview публикуется с этими ограничениями. Установленная рабочая версия
владельца при подготовке релиза не заменялась.

`XMLDocument::Load` / `SceneEditorDrawerWnd` при выходе остаётся известной проблемой.

## NNG Mac Easy 1.4.0 preview — 2026-11-01

Отдельная упаковка автоматической установки, данные `NNG Mac Easy`.

- Пустая тестовая папка: загрузка оригинального 11-МБ архива апдейтера с сервера,
  проверка SHA-256, извлечение и запуск оригинального ARM64 updater v1.2 прошли.
- Он получил актуальный manifest из 2031 файлов / 10.8 GiB и начал реальную
  загрузку. Полная передача всех 11 ГБ с пустого кеша **не завершалась**: после
  проверки этого пути тест остановлен, остальные файлы помещены в отдельный
  кеш APFS-клонами из имеющейся установки, только по списку manifest.
- Апдейтер заново прочитал и проверил все 2031 файла / 10.8 GiB по хешам.
- Архив L2Craft (497719130 байт) заново скачан с исходного публичного сайта;
  SHA архива и всех 16 выбранных модулей прошли проверку.
- Создан новый CX26 Wine prefix без копирования реестра/аккаунтов владельца.
  Wine-архив взят из ранее проверенного SHA-кеша; путь его upstream-загрузки
  проверялся отдельно при подготовке Community preview.
- Повторный `--setup-only` сохранил намеренно изменённый User.ini тестовой игры.
- Намеренно испорченный `system/optiondata_server.ini` в тестовом кеше
  восстановлен тем же апдейтером с реального сервера.
- Занятый `.launch.lock` предотвращает повторную установку/запуск.
- В новом prefix скрытый D3D9 probe успешно выполнил CreateDevice и 12
  Clear/Present; Wine подтвердил выбор `d3d9 = mtld3d`.
- В реестре подтверждены `AllowSetGamma=N` и `UsePreciseScrolling=n`.
- Начальное окно проверено визуально: «Установить и играть», без выбора готового
  клиента. Подписи основного приложения и helper проверяются `codesign`.
- Общие тесты импорта Community после изменений также прошли.

Rosetta уже установлена на тестовом Mac; её удаление и повторная установка
ради теста не выполнялись. Новый диалог принятия лицензии и установка на системе
без Rosetta пока не прошли физическую проверку. Не выполнялся вход в игровой
мир новым Easy-приложением. Проверка на другом Mac остаётся отдельной приёмкой.
Рабочие приложение/игра владельца при этих проверках не заменялись.
